# Lip Service

A gentle vocal warm-up to play in the car on the way to a gig.

**Open it:** https://davyrockett.github.io/vocal-warmup/
On iPhone: open it in Safari → Share → **Add to Home Screen**. After that it works with no signal.

## Using it

1. Pick **Baritone** or **Tenor**, **Short** (about 4 min) or **Full** (about 10 min), and tap the
   **metronome icon** if you want a click on every beat.
2. Tap **Start** before you pull out, then lock the phone.
3. It plays through Bluetooth or CarPlay (it shows up in **Now Playing**). The car's or headphones'
   **skip buttons** jump to the next or previous exercise.

There's no voice: the instructions for each exercise are written on screen (read them before you go).
A soft chime marks each new exercise. Then, for each key, you hear a chord on a warm synth, then the notes to
sing along with, a half step higher each time. Full climbs higher and then comes back down a few keys.
The player shows each key's notation (bass clef for baritone, tenor treble clef for tenor) with the current
note lit up in orange, like Page Fright's Read section, plus the key and tempo. Slides are drawn as glissando lines.
Breathing: breathe in while a soft chord swells, then hiss through the ticks until the high tick (the counts light up).

## The exercises

| | |
|---|---|
| Breathing | In for 4, hiss out for 8, 10, 12 |
| Humming | "mm", 5 notes down |
| Lip trills | 5 notes up and back down |
| Lip trill sirens | slide up an octave and back |
| Sighs | breathy "hoo", sliding down an octave |
| NG slides (Full) | "ng" slide up a fifth and back |
| Vowels | mee may mah moh moo, 5 notes down |
| Yah arpeggios (Full) | 1-3-5-3-1 |

The note range for each exercise is listed in the app. Tenor is 3 half steps higher than baritone.

## Settings (gear icon)

Appearance (Light / Dark / Auto) and Check for updates.

## If it stops when the phone locks

Older iPhones sometimes pause Home Screen apps when locked. Open the link in Safari instead and play it from there.
